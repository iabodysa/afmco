# AFMCO 0.0.21

## Added

- Accounts Settings has a **Journal Entry Draft Limit per User** field in the Others tab. It is set to 50, and 0 removes the limit. Open: [/desk/accounts-settings](/desk/accounts-settings)

- Journal Entry has an **Attachments View** button in the toolbar. It opens the attachments of the entry and its Payment Requisition in the right half of the screen, beside the form, to compare them. The same button closes it.

## Fixed

- My Tasks counts and lists only documents in a state that awaits action, newest first. Open: [/desk/action-inbox](/desk/action-inbox)
- Expense Request Dashboard charts and cards load after the Payment Requisition rename
- The Journal Entry tab that holds the employee field is labelled Employee

## Removed

- Financial Analysis Dashboard, an unfinished attempt
