# AFMCO 0.0.19

AFMCO runs on Frappe v16 with My Tasks, the new login page and desk links that open under /desk

- My Tasks workspace, sidebar and desktop tile under AFMCO open the Action Inbox page and four number cards: Pending My Action, Acted On My Documents, Unread Notifications and Submitted By Me
- The login page shows the AFMCO green band and background, and the email field placeholder reads name@afmco.sa in Arabic and English
- Apex, Care, My Workspaces and Home desktop tiles show their logos
- Links from WPS File, Employee, Employee Financial Summary, Payroll Entry, Iqama Control and SADAD Bulk open directly under /desk, and the WPS report email links IBAN Update at /desk/iban-update
- AFMCO modules People and Payroll and Financial Operations run on Frappe v16, and the v16 patch set deletes no business record
- Retired server and client scripts run from DocType controllers; the Client Script cutover disables each retired script and keeps its record
- Twenty-two print formats ship as standard under English names with the shared AFMCO identity header
- WPS File and SADAD Bulk desk pages issue bank files and bulk SADAD payments
- Expense Request and PR dashboards ship their charts and number cards as standard
- Empty workspace, sidebar and number card icons and colours fill after every migrate
