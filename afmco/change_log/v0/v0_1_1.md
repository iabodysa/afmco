# AFMCO 0.1.1

The desk opens again on Frappe 16.50: the AFMCO boot hooks read the 16.50 sidebar payload.

- Fleet items (Vehicle, Driver, Vehicle Log, Vehicle Service Item, Vehicle Expenses) are removed from the desk sidebar on Frappe 16.50, which sends module sidebars, and on earlier 16.x, which sends workspace sidebars.
- The desk boots when the Apps desktop page is selected, where Frappe sends no desktop icons.
