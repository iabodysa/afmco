# AFMCO 0.1.1

The desk opens on Frappe 16.50 with no AFMCO code in the boot payload: what each user sees follows Frappe's own roles, Module Profile and record settings.

- Fleet items (Vehicle, Driver, Vehicle Log, Vehicle Service Item, Vehicle Expenses) appear in the sidebar and workspaces only for users whose roles can read them, through Frappe's own permission filter.
- A blocked module follows the user's Module Profile as Frappe applies it, with no AFMCO override of the workspace page or the sidebar item check.
- The Organization desktop icon takes its picture from the icon's own logo field.
