# AFMCO 0.0.22

## Added

- Journal Entry has an **Attachments View** button (paperclip) in the toolbar. It opens the attachments of the entry and its Payment Requisition in the right half of the screen, beside the form, to compare them. The same button closes it.
- Action Inbox Settings has a **Pending Action Window (Days)** field. Pending My Action counts only workflow actions created in that window, and it starts at 1, which means today. Open: [/desk/action-inbox-settings](/desk/action-inbox-settings)

## Fixed

- The Journal Entry employee field sits in the first tab, after Company, and the separate Employee tab is gone
- Report exports sent by email no longer fail when the report name and filters make a long file name
