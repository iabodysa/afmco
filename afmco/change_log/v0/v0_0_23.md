# AFMCO 0.0.23

## Moved to Apex

- Moved employee transfer requests to Apex as transport requests, with their status; create new requests in Apex
- Opening an old transfer request in AFMCO takes you to the same request in Apex; accountants keep the AFMCO list for payment orders

## Changed

- Added a welcome on the portal for newly arrived employees
- Hid the staff portal pages from search engines
- Added the IBAN update, leave request, contact and job application forms to the portal list
- Opening a failed data import no longer shows a permission message; the Report Error button shows only to users who can read error logs
- Removed the unused year field from purchase invoices
- Removed the unused journal, sales, purchase and payment series fields from the company form
- Renamed the expense request dashboard and its four charts to payment requisition names
- The WPS report downloads the same bank files as the WPS Consolidated Report, built on the server
- WPS bank files show the IBAN holder name for employees paid to a temporary IBAN
